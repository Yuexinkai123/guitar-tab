# Songscription 转谱效果研究与本次实现

研究日期：2026-10-08。目标是改进音乐识别和出谱能力，页面没有照搬。

## 公开资料确认的能力

- [官网与 FAQ](https://www.songscription.ai/cn)：官方称使用专为转谱训练的自研模型；单乐器和混音多乐器转谱是不同场景，多乐器功能标为 beta。官方也提示密集混音会需要修正。
- [吉他六线谱功能页](https://www.songscription.ai/cn/guitar-tab-generator)：从录音中的吉他声部识别音符、节奏并安排指板位置；木吉他较适合，重失真更困难。支持谱编辑和 PDF、MIDI、MusicXML、Guitar Pro 等导出。
- [公开样谱](https://www.songscription.ai/transcribe/66627d3a-f30a-4a86-98d8-1950eb964600)：页面可见乐谱、钢琴卷帘、原录音等入口。本次未完成其结果逐音核验。

以上是公开产品说明，不能当作独立准确率测评。网站没有公开足够的模型、训练数据和推理实现，无法确认其内部具体架构，也没有复用其模型或代码。

## 原程序的主要差距

原来把 Demucs 分离的人声交给 pYIN 单音跟踪，再将演唱旋律安排到吉他上。这适合弹主旋律，但无法还原吉他和弦、前奏及分解和弦。改变网页样式不能解决此差距。

## 本次实际实现

1. **吉他声部提取**：完整混音使用 Demucs `htdemucs_6s` 的 guitar 声部；纯吉他跳过分离。原来的人声改编模式继续保留。
2. **多音转录**：Spotify Basic Pitch 0.4.0 的原始 ONNX 权重及 Apache-2.0 解码器识别重叠音符与起音，CPU 本地运行。平均激活低于 0.45 的音暂不收录；该阈值是实用过滤，未经大规模吉他数据集校准。
3. **多音指法**：beam search 保持原音高，禁止同时占用同一根弦，限制非空弦品位跨度，并考虑换把。无法安排的音明确计入省略数。推算指法不能保证与演奏者的原始指法一致，也未建模所有手指、横按、击勾弦与扫弦技巧。
4. **完整时间轴**：继续分段处理长曲；对跨边界的延音使用上下文和截断标记合并，避免把每个重复拨弦都合成长音。
5. **试听与修订**：和弦中的多个音同时播放、高亮；保留进度、拖动、暂停续播和调速。手动修改会检查同弦同时发声冲突。
6. **标准格式**：MIDI 保留实测时间；MusicXML 输出六弦 TAB、休止、估计时值、跨小节延音。使用参考 BPM 或用户修改的 BPM，拍号由用户指定；节奏网格从十六分音符起，必要时细分至 128 分音符以保留快音。并没有声称自动识别拍号、调号、自由速度或原曲精确节奏。
7. **结果保存**：完成任务写入本地 JSON，重启可恢复后台结果；页面中的手工编辑仍需及时导出。

## 已有验证与证据边界

- 自制 5 秒、3 次三音和弦（C3/E3/G3、D3/F#3/A3、C3/E3/G3），共 9 个已知目标音。本次模型识别出这 9 个音，起音误差在 60 毫秒以内；过滤前另有低激活泛音误报。这仅是一个受控小样本，不能推算真实歌曲准确率。
- 公开歌曲 `Karissa Hobbs - Let's Go Fishin'`，20～35 秒：实际运行吉他分离与多音识别，安排后 124 个音，省略 1 个无法安排的候选音。导出的 MusicXML 通过 W3C MusicXML 4.0 XSD 校验。音符数量和格式校验不代表逐音正确；此录音没有人工吉他标注。
- 自动测试验证单音旧流程、静音、长歌曲时间、和弦起音、重复音、指法冲突、跨块片段合并、MIDI 实测时间、MusicXML 每小节各声部时值平衡及延音、导出 API 和前端编辑后的导出。
- 没有用同一段录音完成与 Songscription 的 A/B 比较，也没有可以支撑“效果完全一样”的证据。

## 尚存差距及后续评价方法

强失真、两把吉他叠录、弱音、混响、人声或钢琴漏入吉他 stem 仍会导致错音、漏音。Basic Pitch 是通用乐器模型，不是与 Songscription 相同的专有吉他模型。分离不干净时，换一个转录器也无法完全恢复信息。

下一轮应选清晰木吉他、扫弦伴奏、指弹、完整流行混音、失真电吉他各几段，制作人工音符及节奏标注；比较两边的音高/起音/结束时间误差、漏音误报、指法可弹性和修改耗时。只有完成这类同曲对照，才能客观判断是否接近目标。当前没有 Guitar Pro 导出、网页正式节奏谱编辑或真实吉他采样音色。

开源来源：[Demucs](https://github.com/facebookresearch/demucs)、[Basic Pitch v0.4.0](https://github.com/spotify/basic-pitch/tree/v0.4.0)、[MusicXML 4.0 schema](https://github.com/w3c/musicxml/tree/v4.0/schema)。模型许可和解码器改动见 `app/vendor/basic_pitch/`。
